## 2. 번역의 충실도

- **영어 줄과 한국어 줄은 대부분 그대로 대응합니다.** 더한 것은 낱말 풀이 정도입니다.
  - "슬롭(질 낮은 코드)"
  - "퍼징(무작위로 두드려 보기)"
  - "신디 (스리다란)"
- 해설 카드 구간의 한국어 문장은 번역이 아니라 **채널 자신의 해설**입니다(그동안 영어 자막이 없음). 원본에 없는 비유도 더합니다.
  - 예: 폴더 사이 import 금지를 "백엔드에서 서로 다른 프로세스의 모듈을 가져다 쓰지 못하게 경계를 막는 것"에 빗댑니다.
- 원본에 없는 설명을 원본처럼 보이게 한 곳이 하나 있습니다. 도입부에서 되돌림 비율을 "같은 달에 되돌린 커밋"으로 설명하는데, 슬라이드에는 "% of commits reverted"만 있고 기간 정의는 없습니다.
- 챕터 제목의 "주석 99% 금지", "PR 1만 개", "0.5%"는 발표의 말("ban 99% of comments", 10,926, "about half a percent")을 그대로 옮긴 반올림입니다.

## 3. 채널이 더한 것 가운데 쓸모 있는 것

**발표가 말하지 않은 단서를 화면에 띄웁니다.** 우리가 원본에서 따로 찾은 약점 일부를 채널도 짚었습니다.
- "축 이름 없음": 린트 계단 그래프에 무엇을 셌는지 없다는 지적.
- "발표자 팀 자체 집계", "말로는 · 하루 한 번쯤": 릴리스 숫자는 검증할 수 없고, 슬라이드의 중앙값(25·28시간)은 "하루 한 번"보다 조금 깁니다.
- 성능 표의 각주 "there is a ceiling …(i am however toying with the idea of a rust rewrite)"를 강조합니다. 발표자가 말로는 읽지 않은 줄입니다.
- "발표자 팀 제품 · 바깥 루프 권유": Grok Bot 소개가 자기 제품 권유라는 점을 밝힙니다. pstack도 발표자의 플러그인이라고 밝힙니다.
- 마무리: **"주석 거의 0 · PR 자동 병합 = 다른 이야기", "PR 수천 개까지 여섯 달", "숫자 = 그 팀의 코드베이스"**. 끝부분까지 따라 하라는 것이 아니라 피라미드 맨 위 칸부터 하나씩 옮기라고 정리합니다.

**짚지 않은 것**:
- 성능 표의 퇴보 5칸(메모리 +12%, 유휴 CPU +100%, 시작 JS+CSS +285% 등)
- 되돌림 비율이 품질 지표로 갖는 한계(퍼징 보고서의 기존 버그 47개)

## 5. 해석

- **좋은 해설의 형식입니다.** 원문(영어 자막)을 그대로 두고, 해설을 시각적으로 분리하고(보라색 카드), 원본 시각을 붙이고, 제품 홍보와 검증 불가 숫자를 표시합니다. 그래서 이 영상 하나로 원본 발표를 복원할 수 있었습니다.
- **제목은 원본보다 셉니다.** 원본 제목은 농담("Except Mine")이지만, 해설판 제목은 "PR 1만 개, 0.5%만 되돌린 장치들"이라는 숫자를 앞세웁니다. 다만 영상 끝에서 채널 스스로 그 숫자를 "그 팀의 코드베이스에서 나온 것"으로 낮춥니다.
- 피라미드의 글(prose) 칸을 설명하며 이 채널의 이전 영상("영상104", Anthropic Lydia Hallie의 발표: CLAUDE.md에 강조 문구를 쌓지 말라)을 "방향이 같다"고 잇습니다. 이 채널은 AI 에이전트 실무 발표를 한국어로 해설하는 곳으로 보입니다.
