## Observations

- Original talk content here: the general principle "every time we correct our agents, it turns into one of these deterministic checks" (lint it, or redesign API/architecture so the problem category cannot occur). Payoff claimed: fewer things to check in code review, until "nothing left to review", so agents can merge most of their own PRs. The step chart (7 -> 167, Jul-Nov) is the only numeric support shown; the y-axis is unlabeled, so what is counted (lint rules? checks?) is not stated on screen. The speaker's claim that review has "nothing left" and that agents merge "most" of their PRs is a bare assertion with no number on screen.
- Then the talk moves to "verification is the most important step": verification makes agents more autonomous and raises trust; code review has "shrunk into looking at verification artifacts" (videos, screenshots, diagrams, formal verification). Runtime verification is presented as the most basic example (feature map slide, then CLI drive-the-real-app). The CLI lines on the slide are an illustration of the idea; no result or measurement shown in this segment.
- Channel additions (not in the talk at this point): the 12:01-12:36 insert block is a recap by AgentOS, not the speaker. It (a) re-shows the "comments are liabilities" slide (65,824 -> 1,227) from 8:35 with orange boxes and pills "7월 말 65,824" / "지금 1,227"; (b) re-shows the step chart from 9:20 highlighting 7 and 167; (c) adds an unlabeled-axis caveat: "축 이름 없음" (the channel itself points out the chart has no axis name), and summarizes the principle as "교정할 때마다 → 린트·설계"; (d) explains that the small footer text "/no-comments" is a skill name in Lauren Tan's pstack plugin (the English slide only says "also see /no-comments in pstack: github.com/cursor/plugins"); (e) re-draws the pyramid (codebase, static analysis, verification, prose, human review; cost axis) with checks on the first two layers and the verification layer highlighted as "가장 중요한 단계"; (f) re-shows the runtime verification slide at 10:46, highlights the three CLI lines in turn, adds the Korean gloss "앱에서 설정 버튼을 누르고, [스냅샷], 스크린샷을 증거 파일로 남기는 명령", and poses the question "그럼 사람은 무엇을 보나?"
