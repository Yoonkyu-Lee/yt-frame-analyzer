- He writes thoughts in Vietnamese and shows the English via Google Translate. The Notes app is his slide deck: he scrolls through photos, channel screenshots, link previews and code screenshots, and zooms into images in a Preview window to point at details.
- The 2024 note documents his work: the open-source project wingram.org (Go backend, Vue / own JS framework "GramJs" frontend), a YouTube "Study and Code with me" series, "How i use Terminal for anything" (one terminal is enough, no app needed), a 100-line Go file manager, a file-comparison tool, and a live-coded web file manager. This fits a simplicity, minimal-tools, terminal-centric philosophy, and he describes himself plainly as a web developer who loves Go, Vue and pure JS.
