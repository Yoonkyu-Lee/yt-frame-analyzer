## 1. 줄거리: 직접 짜다가 AI를 써 보고, 되돌리고, 자기 규칙을 쓰다

| 시각 | 단계 | 내용 |
|---|---|---|
| 00:00–03:43 | 격자 | `state[30][50]`, `render()`, `init()`(가운데 한 칸에 `1`), `clear_term()`(`usleep` + `system("clear")`)으로 **화면을 다시 그리는 루프**부터 만듭니다. 처음에 `void render()`라고 썼다가 clang의 `-Wstrict-prototypes` 경고를 보고 `render(void)`로 고칩니다. |
| 03:43–08:11 | 이동 규칙 | 이중 버퍼 `next[H][W]` + `memcpy`를 둡니다. 이웃 8칸 오프셋 표 `moves[8][2]`는 가운데(0,0) 자리를 비워 둔 3×3 모양으로 정렬해 적고, `moves[rand() % 8]`로 무작위 이동합니다. 표 끝에 `;`를 빠뜨려 컴파일 오류가 납니다. |
| 08:11–12:16 | 실험 | `next[j][i]--; next[nj][ni]++`이면 전체 양이 보존되어 퍼지기만 합니다. `--`를 주석 처리하면 숫자가 계속 불어나 화면을 가득 채웁니다. 이것이 제목의 "magical numbers"입니다. |
| 12:16–12:48 | **AI 사용** | vim에서 23줄(이동 표와 `update`)을 복사해 Gemini를 거쳐 **ChatGPT(로그아웃 상태)**에 붙여 넣습니다. ChatGPT는 Conway의 Game of Life `update()`를 돌려줍니다. 이웃 수를 세고 B3/S23 규칙을 적용하는 코드로, 4칸 들여쓰기와 `// Count live neighbors` 같은 주석이 붙어 있습니다. |

| 15:41–16:22 | **되돌리기** | vim에서 `u`를 반복해 AI 코드를 걷어 내고 **자기가 쓴 무작위 이동 `update()`로 돌아갑니다**(undo #73 → #66). |
| 16:23–17:03 | 자료 조사 | Google에서 "diffusion"을 검색해 Wikipedia "Diffusion" 문서의 입자 확산 GIF를 오래 봅니다. 이것이 새 목표 동작이 됩니다. |

## 2. 최종 산출물

[src/main.c](src/main.c)

- 구조는 다음과 같습니다.
  - `render`: 0은 공백, 양수는 개수(`%2d`), 음수는 `F`로 출력합니다.
  - `init`: 가운데에 입자 90개, 먹이 4칸(`-4, -2, -1, -7`)을 놓습니다.
  - `update`: 양수 칸마다 무작위 이웃 하나를 고릅니다. 그 칸이 먹이면 먹이를 1 줄이고 이웃 칸에 1을 더합니다. 아니면 입자 하나를 옮깁니다.
  - `main`: `clear_term`, `render`, `update`를 무한히 반복합니다.
- 실행 결과(WSL, gcc 13, 저자와 같은 경고 플래그로 경고 0개): 입자 90개가 가운데에서 나뉘어 퍼지고, 먹이 칸이 `F`로 표시됩니다.

## 4. 해석

- **AI를 써 본 뒤 버리는 과정이 영상 안에 그대로 남아 있습니다.**
  - ChatGPT 코드는 잘 돌았습니다. Life의 정형 패턴이 정확히 나타났습니다.
  - 그런데도 저자는 그 코드를 undo로 걷어 냈습니다. 그리고 Wikipedia를 보며 "입자가 퍼진다"는 **자기가 원래 원했던 동작**을 다시 정했습니다.
  - 마지막 문장 "you write your rule"이 핵심입니다. 이미 있는 규칙(Life)을 받아 오는 것보다 자기 규칙을 쓰는 것이 이 영상의 목적입니다.
- **AI 코드는 스타일부터 다릅니다.**
  - 저자의 코드: 2칸 들여쓰기, 짧은 소문자 주석, `sizeof(int) * W * H`
  - ChatGPT의 코드: 4칸 들여쓰기, 설명형 주석, `(int)j` 캐스트, `sizeof(state)`
  - 붙여 넣은 뒤에도 형식을 고치지 않아서, 어디까지가 AI 코드인지 한눈에 구분됩니다.
- **데이터 표현이 곧 설계입니다.**
  - 칸 하나의 `int` 값 하나로 세 가지를 표현합니다: 0은 빈칸, 양수는 입자 수, 음수는 먹이.
  - struct나 enum을 따로 두지 않습니다. 규칙을 바꿀 때도 `update()`의 두세 줄만 고칩니다.
- **실험이 곧 개발 과정입니다.** 한 줄을 주석 처리하거나 숫자 하나(9→90, 500000→300000)를 바꿀 때마다 컴파일하고 실행해서 화면으로 확인합니다.
